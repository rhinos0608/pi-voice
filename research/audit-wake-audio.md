## Corrections that matter for implementation

1. **Reset call:** use `kws.reset(stream)` instead of `kws.resetStream(stream)`, and call it right after each detection (the Python example says to do this).
2. **Library path:** set `DYLD_LIBRARY_PATH=<project>/node_modules/sherpa-onnx-darwin-arm64`. The brief's `sherpa-onnx-node/lib` path doesn't match the docs. Export the variable in the shell that launches node, because SIP can strip it in some launch paths.
3. **ffplay arguments:** use `-f s16le -sample_rate 24000 -ch_layout mono` and never `-ac`. `-ar` is unconfirmed, so run a quick local test before relying on it.
4. **Keywords file:** don't hand-write `▁P I`. Generate the tokens from the model's `bpe.model` with `text2token`, or check them against `tokens.txt`. Keep the gigaspeech model; wenetspeech is Chinese-only.
5. **Smaller fixes:**
   - Pin `sherpa-onnx-node@1.13.8` (or later), not 1.13.5.
   - Correct the int8 sizes to 272K (decoder) and 160K (joiner); this affects documentation only.
   - The brief's "Missing Evidence: None" and its Node 25 claim are overstated; Node 25 support should be tested with a smoke test.
